Ternary-Bonsai-2-27B-Uncensored-Heretic (PQ2_0) - portable llama.cpp server
===========================================================================

Запуск
------
Двойной клик:  Bonsai 27B PQ2_0.lnk   (или start-bonsai.bat)
Ждать 10-15 секунд, пока в окне не появится:
    model loaded
    listening on http://127.0.0.1:18098

Подключение клиента (OpenAI-совместимый API):
    Base URL : http://127.0.0.1:18098/v1
    API key  : любой текст или пусто
    Model    : любой текст (например "local")

Пример:
    curl http://127.0.0.1:18098/v1/chat/completions -H "Content-Type: application/json" ^
      -d "{\"model\":\"local\",\"messages\":[{\"role\":\"user\",\"content\":\"Привет\"}],\"max_tokens\":512}"

Остановка: закрыть окно или Ctrl+C.

Что внутри
----------
    Bonsai 27B PQ2_0.lnk    ярлык запуска
    start-bonsai.bat        скрипт запуска + настройки
    prism-llama/            движок (llama.cpp форк PrismML, win-vulkan)
    Ternary-...-PQ2_0.gguf  модель, 7.2 GB
    mmproj-BF16.gguf        зрительная башня, для картинок

Настройки (start-bonsai.bat, блок "===== settings =====")
-------------------------------------------------------
    CTX=65536        контекст, токенов (максимум модели 262144)
    THREADS=12      потоков CPU ( Ryzen 5 5500 = 6 ядер / 12 потоков )
    PARALLEL=1      параллельных слотов. 1 = максимум скорости, 4 = вдвое
                    медленнее, зато 4 запроса одновременно
    PORT=18098      порт сервера
    MODEL / MMPROJ  пути к файлам, задаются относительно папки

Переопределение разово из командной строки:
    start-bonsai.bat -c 131072 --port 18099

Картинки (мультимодальность): добавь в строку запуска
    --mmproj "%~dp0mmproj-BF16.gguf"
и не забудь поднять CTX, картинки съедают контекст.

Проверенные параметры генерации
-------------------------------
    thinking  : temperature=1.0  top_p=0.95  top_k=20  min_p=0.05
                reasoning_effort = xhigh (по умолчанию) / medium / low
    instruct  : temperature=0.7  top_p=0.80  top_k=20  presence_penalty=1.5
Модель по умолчанию думает (thinking). Для быстрых ответов ставь
reasoning_effort=medium, иначе ответы будут длинные и медленные.

Замеры на Ryzen 5 5500 + Intel Arc B580 (Vulkan)
------------------------------------------------
    prompt eval : 23-450 tok/s (падает с глубиной контекста)
    decode      : 10-26 tok/s (падает с глубиной контекста)
    загрузка    : 6-12 с
Первый запрос после запуска медленный: страницы модели читаются с диска.

Почему именно такие настройки (проверено A/B)
--------------------------------------------
    -ngl 99      обязателен. Без него llama.cpp часть слоев переносит в RAM,
                 теряется 4-5x скорости decode (23.5 против 4.2 tok/s).
    -t 12        все логические процессоры, +11.8 tok/s к -t 6.
    -np 1        один слот. Это ключевая настройка: при -np 4 контекст делится
                 на 4 части и decode падает вдвое (23.1 против 10.5 tok/s).
                 Ставь -np 2..4 только если реально нужны параллельные запросы.
    -fa on       flash attention, обязателен для гибридной архитектуры.

Влияние глубины контекста на скорость (ctx 65536, decode)
----------------------------------------------------------
    1 038 токенов в контексте  ->  25.9 tok/s
    4 034                      ->  19.4 tok/s
    8 038                      ->  14.0 tok/s
    14 044                     ->   9.9 tok/s

Длинные диалоги сами по себе замедляют отклик. Если задача упирается в
скорость, перезапускай сервер с меньшим CTX - короткий контекст быстрее.

Важно про портативность
-----------------------
    - Папку можно целиком копировать на диск/флешку, путь в bat относительный.
    - Нужны пути к папке без кириллицы и без пробелов (BAT плохо их переваривает).
    - Порядок файлов: .gguf и папка prism-llama должны лежать рядом с .bat.
    - Модель НЕ грузится в LM Studio: тип ggml 142 (PQ2_0) есть только в форке
      PrismML, в стоковом llama.cpp его нет. Обновление LM Studio не поможет.
